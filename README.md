# Homepage

This static homepage is generated from `index.jemdoc`.

## Editing

1. Edit `index.jemdoc`.
2. Run `./build.sh`.
3. Inspect or open `index.html`.

Do not edit `index.html` by hand unless generation is unavailable. The repo includes a local Python 3-compatible Jemdoc generator at `tools/jemdoc.py`, so no global `jemdoc` installation is required.
